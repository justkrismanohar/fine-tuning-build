# Frozen held-out set

`cases.py` is the exact 20-case stress set (7 résumés, 9 tickets, 4 minute excerpts). **Do not train on it.**

`prompts.py` holds the system prompts. Pre-flight and adapter eval must use the same strings.

`eval_tasks.py` scores a run file. Numbers in the notebooks come from that run, not from a briefing note.
