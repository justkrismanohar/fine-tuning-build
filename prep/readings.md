# Optional readings (short)

Skip these if time is tight. The notebooks already teach the words. These pages are for people who want a second voice **before** the room. Read the prose; **do not** paste work files into any demo box.

## Night 1 (after or before PREP-01)

1. **What an LLM is, in plain language** — Hugging Face LLM course, Chapter 1 introduction (stop when they ask you to run code):  
   [https://huggingface.co/learn/llm-course/chapter1/1](https://huggingface.co/learn/llm-course/chapter1/1)

2. **See tokens** — paste a *fictional* CivicDesk sentence (the notebooks give you one) into:  
   [https://tiktokenizer.vercel.app/](https://tiktokenizer.vercel.app/)  
   Switch the tokenizer if you like; the point is only that words split into pieces. You do not need an OpenAI account.

## Night 2 (before PREP-02)

3. **RAG in one sitting** — IBM “What is retrieval-augmented generation (RAG)?”:  
   [https://www.ibm.com/think/topics/retrieval-augmented-generation](https://www.ibm.com/think/topics/retrieval-augmented-generation)  
   Hold one sentence: retrieve an approved paragraph, *then* generate. If the paragraph is missing, stop.

## Night 3 (before PREP-03)

4. **Fine-tuning vs the chatbot you already have** — Hugging Face “Fine-tuning” overview, first screen only:  
   [https://huggingface.co/docs/transformers/training](https://huggingface.co/docs/transformers/training)  
   You will **not** train in Tier 1. You only need: a small extra file can sit on frozen weights; it is not a database.

5. Optional 20-minute video if you prefer listening: 3Blue1Brown, *But what is a GPT? Visual intro to transformers*  
   [https://www.youtube.com/watch?v=wjZofJX3UZc](https://www.youtube.com/watch?v=wjZofJX3UZc)  
   Skip if you are tired. Day 1 T1-02 covers the same picture slowly.

## Do not start here

- Python tutorials (Codecademy, etc.) — the room does not require you to write programs.
- “Build an agent” blog posts — Day 3 is about **not** calling tools.
- Ministry manuals, EDMS exports, live tickets — data ban.
